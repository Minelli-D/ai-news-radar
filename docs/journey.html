Timeline

  1. 1

    The brief

    Kickoff

    The work started with /init in an empty folder, followed by the full brief: six AI news sources, a serverless AWS architecture, Terraform, GitHub Actions, and a hard cost rule of €0 per month.

    • Agreed process: a short plan and verified source URLs first, then six phases with one commit each.
    • Nothing is applied to AWS or pushed to GitHub without the owner's explicit OK.
  2. 2

    Verifying every source

    Research

    Every candidate URL was fetched with the collector's descriptive User-Agent, and every site's robots.txt was read.

    • Anthropic has no RSS feed. Its news page embeds CMS data with the title, date and summary of 267 posts.
    • OpenAI's feed carries its whole history: 1,229 items.
    • www.deepseek.com sends non-browser clients to a page that returns 403. The API docs site lists all 18 announcements in its sitemap and news sidebar.
    • The Google AI feed has moved to a new path, and about 30% of DeepMind items have no description. Google Research was rejected because its descriptions are only category names.
    • AWS tags its own AI announcements, which allows a precise filter. The keyword "agent" was dropped because it matched Amazon Connect's call-centre agents.
    • AI News Hub's page has no dates, so its blog feed is used instead. Its newest post is from 3 June 2026.
    • AWS's robots.txt uses wildcards that Python's built-in parser ignores, so the collector uses an RFC 9309 parser.

    Evidence28 URLs fetched · every robots.txt allows the paths used

  3. 3

    Researching cost and AWS rules

    Research

    Two research agents worked in parallel while the sources were being checked.

    • The CloudFront flat-rate Free plan requires a WAF web ACL, is closed to accounts on AWS's Free plan, and cannot be managed by Terraform's AWS provider. The site stays on pay-as-you-go, whose always-free allowance is 1 TB and 10 million requests.
    • S3 is the only service outside the always-free tier. Writing the feed and redirect pages only when they change keeps it near one cent a month.
    • AWS Budgets count credits by default, which would hide real spending, so the budget excludes them.
    • New accounts often have a Lambda concurrency limit of 10, which rules out reserved concurrency.
    • In March 2026 attackers hijacked the tags of trivy-action. Every action in CI is pinned to a commit SHA.

  5. 5

    Discovering the account's limits

    Research

    Read-only checks showed that awsnew comes from AWS's new sign-up flow and is on the Free plan.

    • AWS-managed service control policies allow regional services only in eu-north-1 (Stockholm).
    • They also deny iam:*Provider*, which blocks the GitHub OIDC provider. The Paid plan has the same rule; only "Activate advanced features" lets the owner remove it.
    • Three options went back to the owner: upgrade and activate advanced features, use another account, or run without CI access to AWS. The Region defaults to eu-north-1 in the meantime.

    Evidenceeu-west-2 calls: explicit deny · eu-north-1 calls: allowed

  6. 6

    The collector, test-first

    Phase a

    Python 3.12, one module per source, a shared NewsItem, and separate modules for HTTP, storage, enrichment, publishing and the run itself.

    • Real responses from 25 September were cut down to a few items, with article bodies removed, and used as test fixtures. The tests block every network connection.
    • Tests caught real problems early. feedparser took an image caption ("Google Beam promotional animation") as the article summary, and a hand-typed TTL value in a test was wrong.
    • A live run collected 118 items from all six sources in 10.6 seconds. DeepSeek answered one request with an intermittent HTTP 400, which was logged and skipped as designed.

    Evidence151 tests passing · ruff and strict mypy clean 5b91e59

  7. 7

    Bootstrap

    Phase b
    • A state bucket for Terraform: versioned, SSE-S3, private, TLS only, with S3-native locking.
    • The GitHub OIDC provider and two roles. The plan role is read-only and trusted only for pull requests. The deploy role is trusted only for the main branch. Both are scoped to the app's exact resource names.
    • A permissions boundary stops CI from creating an over-privileged IAM role.
    • A $5 monthly budget with credits excluded, and S3 Block Public Access for the whole account.
    • Terraform 1.16.4 was installed only after checking HashiCorp's GPG signature and the SHA-256.

    EvidenceDry-run plan against the account: 22 to add, $0 a9e7f5b

    Build

  9. 9

    Infrastructure

    Phase c
    • DynamoDB with 5 read and 5 write units, TTL, and Query-only access.
    • A private S3 bucket served only through CloudFront with Origin Access Control.
    • The Lambda: Python 3.12, arm64, 256 MB, 60 seconds, no VPC. EventBridge Scheduler runs it every hour.
    • An alarm on collector errors that emails the owner through SNS.
    • The collector may write only news.json, feed.xml and latest/*, so it cannot overwrite the site itself.

    EvidenceDry-run plan: 19 to add, about $0.01 a month 499d5c6

  10. 10

    The site

    Phase d
    • Plain HTML, CSS and ES modules. No framework, build step, cookies, trackers or browser storage.
    • The page logic lives in a small tested module. Untrusted text is rendered only with textContent, under a strict content security policy.
    • Every colour pair passes WCAG AA contrast in both light and dark themes.
    • Headless Chrome rendered 60 items and 7 filters, and the #aws link showed exactly 20 AWS items. Light, dark and 390 px layouts were captured.

    Evidence9 site tests passing 049a79a

  11. 11

    Independent code review

    Review

    A separate reviewer read the whole collector and found no critical issues, five important ones and eleven minor ones. The fixes came with regression tests:

    • news.json is written last, so a failed upload is retried by the next run.
    • Feed descriptions are HTML-escaped, because RSS readers render them as HTML.
    • Control characters and broken Unicode are removed before they can make the feed invalid.
    • Each source may link only to its own domains over HTTPS, so a hacked feed cannot hijack /latest/<company>.
    • A malformed URL or an odd page error can no longer take a source down.

    Kept by design, with reasons: Google counts as one source, slow sources re-insert old posts after the 120-day TTL, and Google and DeepSeek each need two requests.

    Evidence152 → 194 tests 4b5cb14

  12. 12

    CI/CD

    Phase e
    • A shared checks workflow runs lint, types, tests, Terraform format and validation, TFLint and two Trivy scans. Pull requests also get a Terraform plan as a comment, with the account ID removed.
    • Pushes to main deploy the stack, upload the site, run the collector once, invalidate /* once and run smoke tests.
    • Every action is pinned to a commit SHA looked up through the GitHub API. trivy-action still runs setup-trivy v0.2.6 internally, from the hijacked tag range, so CI downloads Trivy and TFLint directly and checks them against pinned SHA-256 values.
    • Trivy's one real finding, s3:* on the deploy role, was replaced with explicit actions. The other findings are cost decisions, each documented next to its resource.
    • Running the smoke-test script locally caught a quoting bug before it reached CI.

    Evidenceactionlint, shellcheck, TFLint and Trivy clean 2f830b0

What's next

Decisions for the owner

  • Choose how to handle the account: upgrade and activate advanced features, use another account, or skip CI access to AWS.
  • Provide the email address for alerts.
  • Approve creating the public GitHub repository and pushing.
  • Approve the bootstrap (22 resources, $0) and the first deploy (19 resources, about $0.01 a month).

Manual steps after that

  • If upgrading: activate advanced features and remove the policy that blocks OIDC.
  • Set four repository variables and the ALERT_EMAIL secret.
  • Confirm the SNS subscription email after the first deploy.
  • Put the CloudFront URL in the README.
  • Back up the bootstrap state file, or move it into the state bucket.
  • Optional: protect the main branch so CI must pass before a merge.

Risks to watch

  • OpenAI sits behind Cloudflare, which may block requests from AWS. Only that source would be affected.
  • DeepSeek sometimes answers with HTTP 400. The collector skips it and retries on the next run.
  • AI News Hub has not posted since 3 June 2026.
